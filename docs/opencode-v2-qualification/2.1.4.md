# OpenCode V2 2.1.4 qualification (team launch)

Historical Darwin ARM64 and Linux x64 evidence for the `2.1.4` record in
`src/services/opencode/compatibility/opencode-v2-qualifications.json`. The registry
lists platform admission; this report records the two platform runs below.
See [Windows ARM64 qualification](windows-arm64-2.1.4.md) for the completed strict
native ARM64 app candidate, public runtime 0.0.147 archive checks and actual
published ARM64/x64 cold/warm/explicit-repair/restart proofs, all independently
reviewed. The normal app merge and exact reviewed-tree identity are recorded there.
No credential is recorded here; the provider key was read from the macOS
Keychain (darwin) or an Actions secret (Linux) only at launch.
