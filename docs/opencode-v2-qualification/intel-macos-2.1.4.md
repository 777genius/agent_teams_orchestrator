# OpenCode V2 2.1.4 on Intel macOS

The project owner requested enabling the Intel macOS V2 engine before full
end-to-end qualification on 2026-11-05. This is an explicit risk acceptance,
not a claim that a native Intel team lifecycle has passed. Previous release
artifacts exercised staged Intel server graphs, but did not establish the
complete 2.1.4 team-launch flow. The Intel CI smoke in this change checks native
packaging and server startup; live team and provider verification remain open.
