# Best Practices To Steal Vs Ban

## Steal

- Runtime adapter seam as a first-class architectural boundary
- Worktree-first worker isolation
- Observable-truth watchdog logic
- Explicit local durable store plane
- Headless destination clarity with a real reference runtime
- Strong operator-facing self-critique like `STEELMAN.md`
- Serious cleanup and lifecycle repair surfaces

## Ban

- Correctness that depends too heavily on tmux, shell startup, and pane heuristics
- Role contracts that are cleaner in prompts than in runtime enforcement
- Repo-local truth stretched into pseudo-federation
- Runtime parity illusion under one shared interface
- Runtime artifact pollution near repo truth
- Long-lived compatibility shadows across a widening control plane

## One-line architect summary

`🎯 10   🛡️ 9   🧠 2`

**Copy `overstory` where it is explicit, typed, local, and reference-grade. Ban it where meaning leaks into substrate quirks, prompt discipline, or compatibility residue.**
