# Compare Vs Us

## Thesis mismatch first

This comparison is only fair if we say the products are optimized for different centers.

### Paperclip center

- company control plane
- board governance
- approvals
- budgets
- org chart
- multi-user operator surface

### Our current center

- terminal-first coding swarm orchestration
- deterministic bootstrap
- live teammate control
- local operator cockpit

## Fair verdict

### Where Paperclip is stronger

- durable control-plane state
- approvals and budgets
- company/org model
- multi-user access
- richer persisted governance
- plugin capability contracts

### Where we are stronger

- direct local coding orchestration
- deterministic team bring-up
- teammate spawn/runtime control
- low-latency operator steering
- lower conceptual overhead for active coding swarms

## Best one-line comparison

Paperclip is stronger as a **company operating system for agents**.

We are stronger as a **terminal-first orchestrator for coding teams**.

## Important caution

If we copied Paperclip whole, we would gain:

- governance depth

but we would also inherit:

- heartbeat cost tax
- broader product complexity
- weaker coding-cockpit ergonomics

So the right move is not "become Paperclip".

The right move is:

- borrow its durable control-plane ideas
- keep our stronger coding-runtime center
